# FinFut

Caixa única do casal. Next.js + Supabase.

## Rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000), crie a conta (primeiro acesso) e preencha os dois salários em Configurações.

Se o cadastro pedir confirmação de e-mail, desative **Confirm email** em Authentication > Providers no painel do Supabase.
